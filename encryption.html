Technical details: why does tampering fail?
GCM computes an authentication tag over the ciphertext. Change one bit and the tag no longer matches, so decryption refuses to return anything. This is the "integrity" in TLS. TLS uses AES-GCM or ChaCha20 for all page data because symmetric encryption is very fast.

A post box with a slot

Anyone can post through the slot (public key); only the owner opens it (private key).

TLS 1.3 does not encrypt data with RSA. Asymmetric keys are used for the key exchange (Diffie-Hellman) and signatures; the data itself uses fast symmetric AES.
