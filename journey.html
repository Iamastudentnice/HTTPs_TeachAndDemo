        Journey of a Website Completed
        
  
        That is the journey behind a simple website visit.
        
  
          
    
        1. Your browser read the address.
          2. 
    
        2. It checked what was already saved.
          3. 
    
        3. DNS turned the name into an IP address.
          4. 
    
        4. Your router sent the data out towards the website.
          5. 
    
        5. A TCP connection was set up.
          6. 
    
        6. TLS secured the connection.
          7. 
    
        7. The browser asked for the page and got it back.
          8. 
    
        8. The browser drew the page on your screen.
          9. 
  
        
  
        Remember: this is a simplified model. Real browsers can skip, combine or reorder some
    stages because of caching, connections that are already open, the protocol in use and network conditions.
