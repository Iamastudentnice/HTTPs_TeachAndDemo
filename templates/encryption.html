Why does tampering fail?
GCM computes an authentication tag over the ciphertext. Change one bit and the tag no longer matches, so decryption refuses to return anything. This is the "integrity" in TLS.

A post box with a slot

Anyone can drop a letter in through the slot (public key), but only the owner's key opens the box (private key).

TLS 1.3 does not encrypt data with RSA. Asymmetric keys are used for the key exchange (Diffie-Hellman) and signatures; the data itself uses fast symmetric AES.
