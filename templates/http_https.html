Understanding HTTP vs HTTPS

HTTP is like sending a postcard: everyone who handles it can read it. HTTPS puts the same message in a locked box that only you and the website can open.

HTTP

HyperText Transfer Protocol

The language browsers and web servers use to request and send pages. It sends everything as readable text.

HTTPS

HTTP Secure

Exactly the same HTTP messages, but carried inside an encrypted TLS connection (port 443).

TLS

Transport Layer Security

Encrypts the data, detects tampering, and checks the server's certificate to prove its identity.

Why?

Why HTTPS exists

The web started on HTTP. Once people sent passwords and card numbers, anyone on the network path could read or alter them.
