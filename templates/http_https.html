    Technical details: HTTP, HTTPS and TLS defined

    HTTP HyperText Transfer Protocol - the language browsers and servers use. It sends everything as readable text (port 80).

    HTTPS Exactly the same HTTP messages, carried inside an encrypted TLS connection (port 443).

    TLS Transport Layer Security - encrypts the data, detects tampering, and checks the server's certificate.

    Why The web started on HTTP. Once people sent passwords and card numbers, anyone on the path could read or alter them.
