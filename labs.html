Technical details: the three jobs of TLS

Confidentiality - data is encrypted, so eavesdroppers see only ciphertext.

Integrity - authenticated encryption detects any change made in transit.

Authentication - the certificate proves the server controls the domain name.

Learn more: what HTTPS does not do

It does not prove a website is honest (scam sites have padlocks too), it cannot protect a device that already has malware, and it does not hide which servers you connect to. Interception is still possible if a user clicks through a certificate warning, a malicious root CA is installed, or the first visit is downgraded to HTTP without HSTS - the MITM lab demonstrates each case.

Python builds each simulation as a list of steps (real ciphertext, real key exchange, real certificate checks) and returns it as JSON. JavaScript only animates it.

All networks, packets and attacks are simulated inside this application - no real traffic is touched. Keys, ciphertexts, hashes, signatures and certificates are generated for real by Python's cryptography library.
